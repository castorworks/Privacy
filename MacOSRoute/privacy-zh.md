# 隐私政策

生效日期：2026 年 9 月 14 日

本隐私政策适用于 MacOSRoute（Bundle ID：`com.hyperits.app.MacOSRoute`，以下简称“本应用”），以及其后台服务（`com.hyperits.app.MacOSRoute.helper`，以下简称“后台服务”）。

本应用是一款管理 macOS IPv4 路由的工具。它让指定的 IP 地址、网段和域名始终经由您选择的出口访问（例如在开启 VPN 时经由物理网络的网关），并在网络变化后自动重新应用这些路由。本应用完全在您的 Mac 上运行，没有账号体系，没有我们自己的服务器，也不做任何数据统计。请在使用本应用前仔细阅读本政策。

## 1. 我们处理哪些信息

### 1.1 您创建的规则与设置

使用本应用时，您可能会在 Mac 上创建并保存以下信息：

- 路由规则：您添加的 IP 地址、网段（CIDR）和域名
- 每条规则的备注、分组名称、启用状态、优先级和出口选择
- 设置项：首选网卡、DNS 模式、自定义 DNS 服务器、重新解析间隔、旧解析结果的保留时间、暂停状态等

以上信息保存在本机的 `/Library/Application Support/MacOSRoute/` 中，使后台服务在应用窗口关闭或应用未运行时，也能让路由持续生效。

### 1.2 路由与 DNS 状态

为了保持路由一致、并在重启后安全恢复，后台服务会在本机保存以下信息：

- 其添加或接管的路由记录，包括目标地址、网关和网卡（`applied.json`）
- 规则中域名的解析结果及解析时间（`dns.json`）
- 运行日志，其中包含规则目标、解析出的 IP 地址、网关地址、网卡名称和错误信息（`/Library/Logs/MacOSRoute/helper.log`）

此外，本应用会在 macOS 标准偏好设置中保存窗口大小、位置等普通的本地偏好。

### 1.3 您 Mac 的网络配置

为了确定路由应当指向何处并提供诊断信息，本应用会从 macOS 读取以下信息：

- 当前网络的网卡、本机 IP 地址、子网掩码、网关（路由器）和 DNS 服务器
- 系统 IPv4 路由表

这些信息仅在您的 Mac 上读取和处理，不会发送到任何地方。

### 1.4 本应用发出的网络请求

本应用不会与我们运营的任何服务器通信，仅在以下情况下发出网络请求：

- **域名规则的 DNS 查询。** 为获取规则中域名的 IP 地址，本应用会发送包含这些域名的 DNS 查询。根据您选择的 DNS 模式，查询会发送到：
  - 当前物理网络的 DNS 服务器（默认）；仅当这些服务器无响应时，才会经由物理网卡改用公共 DNS 服务器 `223.5.5.5`（阿里云）、`119.29.29.29`（腾讯云 DNSPod）和 `8.8.8.8`（Google Public DNS）；
  - macOS 中配置的 DNS 服务器（“系统 DNS”模式），可能由您的 VPN 或代理软件提供；或
  - 您自行填写的 DNS 服务器（“自定义 DNS 服务器”模式）。
- **您发起的诊断。** 当您对输入的目标执行诊断时，本应用会同时使用物理网络的 DNS 服务器（含上述备用公共 DNS）和 macOS 中配置的 DNS 服务器查询该目标以便对比，并查询系统路由表，并在您指定的端口上尝试与每个解析出的地址建立 TCP 连接，以测量连接耗时。这些连接不发送任何应用数据，并会立即关闭。

接收这些查询的 DNS 服务器能够看到被查询的域名以及查询来源的 IP 地址，并依据其各自的隐私政策处理这些信息。本应用创建的路由会改变您 Mac 网络流量的转发方式，但本应用不会检查、记录或修改这些流量的内容。

### 1.5 系统权限

本应用可能请求以下权限，每项权限仅用于所述用途：

- **管理员授权。** 安装、更新或卸载后台服务需要管理员密码。密码在 macOS 标准授权对话框中输入并由 macOS 处理，本应用无法看到或保存该密码。
- **后台项目。** 后台服务以系统 LaunchDaemon 方式运行，以保证路由持续生效。macOS 会在“系统设置 → 通用 → 登录项与扩展”中列出该项目，您可以随时查看。
- **本地网络访问。** 诊断功能可能会向本地网络中的 DNS 服务器发送查询，macOS 可能为此请求本地网络访问权限。
- **登录时启动。** 如果您开启“登录时启动”，本应用会向 macOS 注册，在您登录时自动启动。您可以随时关闭。

本应用不会请求访问您的通讯录、照片、位置、摄像头、麦克风、文件或其他个人数据。后台服务仅接受在管理员账户下运行、且经过签名的 MacOSRoute 应用发出的指令。

### 1.6 导入与导出

使用导入或导出功能时，本应用仅读取或写入您在 macOS 标准文件对话框中选择的文件。导出的文件包含您的规则和设置，仅保存在您选择的位置。

## 2. 我们如何使用信息

我们仅将上述信息用于以下目的：

- 添加、校验、修复和删除规则所定义的路由
- 检测网络变化，确定正确的网关和网卡
- 解析规则中的域名，并让近期使用过的地址继续保持路由
- 在应用中显示规则状态、系统路由表、诊断结果和日志
- 在您要求时导入和导出规则

## 3. 我们如何共享信息

我们不会在我们的服务器上收集您的信息，不会出售个人信息，也不会将数据用于广告或跨应用追踪。本应用不包含任何数据分析、广告或崩溃报告 SDK。

仅在以下情况下，信息会离开您的 Mac：

- 规则或诊断中的域名，会以 DNS 查询的形式发送到第 1.4 节所述的 DNS 服务器
- 对您输入的诊断目标地址进行 TCP 连接测试

## 4. 数据保留

所有数据均保存在您的 Mac 上：

- 规则、设置、路由记录和 DNS 状态保存在 `/Library/Application Support/MacOSRoute/` 中，直到您在应用中删除规则或删除该文件夹。在应用中卸载后台服务时会保留规则，重新安装后即可恢复。
- 域名不再解析到的旧地址，会在您设置的保留时间（默认 6 小时）后删除。
- 应用内的日志页面仅显示最近的记录；日志文件 `/Library/Logs/MacOSRoute/helper.log` 会一直保留，直到您将其删除。

如需删除本应用产生的全部数据，请先在应用设置中卸载后台服务，再删除本应用，然后删除 `/Library/Application Support/MacOSRoute` 和 `/Library/Logs/MacOSRoute`（需要管理员权限）。

## 5. 您的选择与控制

您可以通过以下方式控制本应用对数据的处理：

- 随时添加、编辑、停用或删除规则，或暂停全部路由
- 使用 IP 地址和网段规则代替域名规则，以避免 DNS 查询
- 在设置中选择域名解析所使用的 DNS 服务器
- 卸载后台服务，这会删除本应用添加的路由
- 关闭“登录时启动”，并在系统设置中查看后台项目
- 在系统设置中撤销本地网络访问权限

## 6. 儿童隐私

本应用并非专门面向儿童设计。我们不会有意通过本应用收集儿童的个人信息。

## 7. 跨境传输

我们不会传输您的数据。发送到第 1.4 节所列公共 DNS 服务器或您自行配置的 DNS 服务器的查询，可能会在这些服务提供商运营所在的国家或地区进行处理。

## 8. 本政策的变更

我们可能会根据功能变化、法律要求或产品更新不时修订本隐私政策。如有重大变更，我们会在此处发布更新后的版本。更新后的政策自发布之日起生效。
